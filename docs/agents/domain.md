# Domain Docs

This is a single-context repository.

## Before exploring

- Read the root `CONTEXT.md`.
- Read relevant decisions under `docs/adr/`.
- If either location does not exist, proceed silently.

## Vocabulary

Use the canonical terms defined in `CONTEXT.md`. Avoid synonyms that the
glossary explicitly rejects.

## ADR conflicts

If proposed work contradicts an ADR, surface the conflict instead of silently
overriding the decision.
